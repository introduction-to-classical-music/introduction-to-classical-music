# 不全书 0.1.2 发布说明

0.1.2 是安全加固与发布工程收口版本。

> **Windows 安装说明**：当前安装包尚未使用代码签名证书，Windows 可能显示“未知发布者 / Windows protected your PC”。请核对 Release 中的 SHA256/SBOM，或从源码构建；正式签名版本将在后续版本发布。

## 主要变化

- 密钥：桌面 LLM 配置与 RRS `llm.local.json` 改用 Windows DPAPI（CurrentUser）；旧明文自动迁移；owner 前端不再持久化 API key。
- 桌面：Electron `sandbox:true`（保留 contextIsolation/webSecurity、关闭 nodeIntegration）；owner/本地站点增加 CSP 与安全响应头；preload 按窗口拆分，IPC 校验发送窗口。
- 隐私/稳定性：默认库使用手册截图移除构建机路径；日志脱敏；RRS job TTL/保留上限/取消/body 上限/日志写 AppData。
- 供应链：运行时依赖升级；`security/DEPENDENCY-EXCEPTIONS.md` 逐条登记残余 high/critical 与可达性；SBOM/THIRD_PARTY_NOTICES；`audit:release` gate。
- 发布工程：RRS lock hash、父/子快照身份、SBOM/checksums、payload/PE metadata 校验；stable tag 继续保留签名 gate，本次通过一次性人工 unsigned 通道发布。

## 已知限制

- 安装包未签名；SmartScreen/企业终端可能警告或拦截。
- 安装/首启/GUI 自动化 BVT 在当前 unsigned 环境未能完整执行；建议在隔离 Windows 环境自行验证并备份资料库。
- 无应用内自动更新；请手动下载新版本。
- 依赖例外复审日期 2026-12-31；Astro 等上游公告按例外矩阵接受。

## 校验

- `SHA256SUMS.txt` / `checksums.json`
- `SBOM.md`、`THIRD_PARTY_NOTICES.md`
- 安装包内 app PE `ProductName=不全书`、`ProductVersion=0.1.2`
