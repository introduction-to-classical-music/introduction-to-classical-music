# 不全书 0.1.2 发布说明（Release Candidate）

0.1.2 是面向商业/开源发版的安全加固版本（候选，未签名）。

- 密钥：桌面 LLM 配置与 RRS `llm.local.json` 改用 Windows DPAPI（CurrentUser）；旧明文自动迁移；owner 前端不再持久化 API key。
- 桌面：Electron `sandbox:true`（保留 contextIsolation/webSecurity、关闭 nodeIntegration）；owner/本地站点增加 CSP 与安全响应头。
- 稳定性/隐私：RRS job TTL/保留上限/取消/body 上限/日志写 AppData；日志脱敏；默认库使用手册截图移除构建机路径。
- 供应链：运行时依赖升级；`security/DEPENDENCY-EXCEPTIONS.md` 逐条登记残余 high/critical 与可达性；SBOM/THIRD_PARTY_NOTICES；`audit:release` gate。
- 发布：正式 Release 需有效 Authenticode 签名；无证书仅允许 Release Candidate。

已知残余：installer 未签名（候选）；构建产物需从本提交重建并执行 `audit:release`/安装验收；Astro 上游公告按例外矩阵接受并复审至 2026-12-31。
