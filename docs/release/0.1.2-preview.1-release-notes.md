## 下载

- 安装包：`buquanshu-setup-0.1.2.exe`
- 校验：下载 `SHA256SUMS.txt` / `checksums.json`，核对 SHA256
- 软件物料：`SBOM.md`、`THIRD_PARTY_NOTICES.md`、`LICENSE`、`NOTICE`
- 版本检索工具：`recording-retrieval-service-portable-0.1.2.zip`（sidecar build-info 含 hash）

## 0.1.2 主要变化

- LLM 配置改为 Windows DPAPI 加密（desktop/RRS），owner UI 不再持久化明文 key；
- Electron `sandbox:true`、contextIsolation、CSP/安全响应头、远程图片逐跳 SSRF 校验；
- owner 鉴权大小写绕过修复；本地资源打开增加可执行类型拒绝与 realpath 校验；
- preload 按窗口拆分（launcher/owner/本地站点/RRS），每个 IPC handler 校验发送窗口；
- RRS job TTL/取消/body 上限/日志目录；RRS 依赖 hash-locked、父快照身份可复现；
- 依赖升级与 19 条 allowlist 例外（`security/DEPENDENCY-EXCEPTIONS.md`，复审 2026-12-31）；
- 打包瘦身/PE metadata、SBOM、checksums、CI release gates。
