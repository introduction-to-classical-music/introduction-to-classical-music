# 0.1.2 安装说明

1. 从 GitHub Release 下载 `buquanshu-setup-0.1.2.exe`。
2. 运行安装程序并选择安装目录。
3. 启动后确认启动器显示 `版本 0.1.2`。
4. 默认活动库位于 `%APPDATA%\buquanshu\libraries\default-library`，默认不包含真实条目。

> 当前安装包尚未使用代码签名证书；Windows 可能提示“未知发布者”。请只从官方 Release 下载，并用 `SHA256SUMS.txt`/`checksums.json` 校验。企业/受管设备可能禁止运行 unsigned 安装包。
