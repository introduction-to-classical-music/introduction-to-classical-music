## 验证与边界

- 人工完成安装版前七步复测；开发版隔离由本机独立检查确认：开发 AppData 位于 `output/desktop-dev-appdata`，安装版位于 Windows 用户 AppData，公开 `data/library` 为空。
- A/B library 可报告 5 条对方新增、5 条本地独有、5 条相同和 4 条冲突；连续冲突的 UI 状态流已修正。
- 根路径站点、相对路径本地导出和 Pages 子路径构建属于不同产物；正式站点仓库不追踪软件源码或 AppData。
- 老私有仓库保持 Archived，仅供历史回滚，不参与构建。

## 下一步行动

1. 对 Windows 打包版建立持续的真实桌面交互回归测试，覆盖多条冲突连续确认、安装升级和服务重载。
2. 完成官方 library 经安装版维护、审计、提交后与根域名站点及 Pages 镜像的同源发布演练。
3. 审查站点仓库当前未提交图片变更，确认来源后单独处理；不把它们混入软件发布。
4. 在回滚期限结束后清理历史 AppData 和 `manual-test` 归档，保留必要的 Git bundle 与发布记录。
